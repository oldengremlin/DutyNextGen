# Duty NextGen

Наступне покоління проєкту **Duty** — планування чергувань системних
адміністраторів із синхронізацією в CalDAV.

Замінює застарілу реалізацію (Perl CGI + CVS, кореневий каталог репозиторію)
новим стеком на Java, зберігаючи всю історію графіків з листопада 2008 року.

Поки застарілий проєкт лишається основним і продовжує працювати —
`nextgen/` розробляється незалежно й нічого в кореневому каталозі не змінює.
Коли з'явиться власний CI/деплой-цикл, цей каталог буде винесено в окремий
репозиторій (`git subtree split`) зі збереженням історії комітів.

## Що змінюється відносно застарілого проєкту

| Було | Стає |
|---|---|
| Perl CGI (`index.pl`) | Java / Spring Boot (Thymeleaf) |
| Редагування графіка вручну через CVS-клієнт (`checkout` → `vim` → `commit` → кнопка «Refresh» на сайті) | Редагування прямо у веб-інтерфейсі |
| CVS (pserver, окремий xinetd-сервіс) | Git — лише як внутрішній, автоматичний журнал змін (кожне збереження в вебі = один коміт), непомітний для користувачів |
| Кодування даних KOI8-U | UTF-8 |
| `tds.pl` (генерація наступного місяця) | Java-порт тієї ж ротаційної логіки |
| `duty2ics.pl` + `duty-caldav-sync` (демони на shell/Perl, `sleep`-цикли) | Java-сервіс з фоновими задачами (JDK 21 virtual threads) |

Формат файлів графіка (`[ Names ]` / `[ Dates ]` / `[ LastDay0 ]` / `[ LastDay1 ]`,
позначки `D`/`W`/`O`/`I`/`-`) навмисно **не змінюється** — він людинозрозумілий,
добре діффиться в git і вже перевірений з 2008 року. Змінюється лише кодування
(KOI8-U → UTF-8) та спосіб редагування.

## Стек

- Java 21 (Spring Boot 3.3, Maven)
- Thymeleaf — серверний рендер сторінок
- Git (зовнішній процес через `ProcessBuilder`) — внутрішня історія змін
- Без бази даних: дані — текстові файли в `data/duty/`, як і раніше

## Статус

Проєкт у розробці. Дивись `CHANGELOG.md` — що вже реалізовано.

## Збірка та запуск

```sh
cd nextgen
mvn spring-boot:run
```

За замовчуванням піднімається на `http://localhost:8080`.

Каталог з даними графіка задається змінною середовища `DUTY_DATA_DIR`
(за замовчуванням `./data/duty`). Налаштування CalDAV — `DUTY_CALDAV_BASE_URL`,
`DUTY_CALDAV_USER`, `DUTY_CALDAV_PASSWORD`.

## Дані та історія

`data/duty/` містить місячні файли графіка (листопад 2008 — жовтень 2026,
216 файлів разом із `vacation`), імпортовані з CVS-репозиторію застарілого
проєкту — 472 git-коміти з оригінальними датами й авторами ревізій
(`nextgen/tools/import-cvs-history.pl`, виконано одноразово, дивись
`CHANGELOG.md` щодо деталей — зокрема, чому 166 найстаріших місяців мають
лише один коміт кожен). Оригінальний CVS-репозиторій
(`../safe/duty/cvs/cvsroot/`) лишається недоторканим як довідкове джерело.

Подивитись історію конкретного місяця:

```sh
git log --follow -- nextgen/data/duty/202409
```
