# Changelog

Усі значущі зміни цього проєкту описуються в цьому файлі.

## [0.2.0] — 2026-09-02

### Додано

- Історію графіків чергувань 2008-2026 (`data/duty/`) імпортовано з CVS
  застарілого проєкту в git: 216 файлів (215 місяців листопад 2008 —
  жовтень 2026 + `vacation`), 472 коміти з оригінальними датами й
  авторами ревізій.
  - Для 166 місяців (листопад 2008 — серпень 2022) справжня історія
    редагувань у самому CVS не збереглася — репозиторій отримав ці
    місяці одним пакетним `cvs import` 2022-07-26; кожен такий місяць
    представлено одним комітом з чесним поясненням цього факту в
    повідомленні, а не вигаданою датою.
  - Решта (вересень 2022 — серпень 2026) — повна поревізійна історія
    ручних правок (`Spasiba. Abnavil.`, автор `olden`) і автогенерації
    наступного місяця (`script output`, автор `noc`).
  - Технічні "1.1 / Initial revision" ревізії `cvs import` (байт-в-байт
    дублікат наступної ревізії) відкинуто як позбавлені інформації.
  - Чернетку жовтня 2026 (`202610`), яка існувала лише в робочій копії
    застарілого проєкту й так і не потрапила в CVS, перенесено окремим
    комітом без вигаданої історичної дати.
  - Кодування даних змінено з KOI8-U на UTF-8; сам текстовий формат
    ([ Names ] / [ Dates ] / [ LastDay0 ] / [ LastDay1 ]) не змінювався.
  - Інструмент імпорту — `nextgen/tools/import-cvs-history.pl` (одноразовий,
    повторний запуск не потрібен).

## [0.1.0] — 2026-09-02

### Додано

- Ініціалізація проєкту `nextgen` — наступного покоління Duty на Java 21 /
  Spring Boot 3.3 / Maven, як незалежний підкаталог у тому самому
  репозиторії (майбутній кандидат на виніс в окремий репозиторій
  `DutyNextGen` через `git subtree split`).
- Мінімальний скелет застосунку, що піднімається (`DutyNextGenApplication`,
  `HomeController`, `home.html`), конфігурація каталогу даних і CalDAV
  через `application.yml` / змінні середовища.
- Власні `README.md`, `CLAUDE.md`, `.gitignore` для підкаталогу.
